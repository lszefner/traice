# Graph analysis and ML experiment

Run after importing the snapshot into a GDS-enabled Neo4j instance. Configure `NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD` and optionally `NEO4J_DATABASE`, then run `python scripts/graph_analysis.py`. It creates a temporary undirected Article–Topic GDS projection, computes weakly connected component statistics and node similarity, streams the top article-pair examples and drops its projection even on algorithm failure. WCC describes disconnected groups; node similarity measures shared topic neighborhoods. The graph's feed-derived labels are coarse, so these scores do not establish that two stories report the same event or paper. Node similarity uses per-node topK before the final pair filter; output is illustrative, not exhaustive.

Run `python scripts/topic_classifier.py data/articles.json` to evaluate article node topic classification from title words. Eligible nodes have a date and exactly one recorded topic; chronological split holds out all articles from the cutoff date onwards. A multinomial naive Bayes model is trained only on earlier articles and evaluated with accuracy against a training-set majority-class baseline. This predicts a feed label, not truth or verified subject matter. Labels are assigned from source feeds, classes and source mix shift over time, later topics may never occur in training, and overlapping multi-topic stories are excluded. The output reports counts, cutoff and unseen labels; results should not be extrapolated beyond the snapshot.

These experiments are deliberately modest. A successful script run is not evidence of a successful live GDS run; report actual results and execution environment separately.
